# 薪火

《薪火》是一个网页端文明生存 roguelite Demo。玩家控制一个单文明，在有限纪元内调度“户”、采集资源、研究科技、修路扩张、建设聚落与仓库，并在灾难季中延续文明。

## 当前版本目标

当前版本目标是完成项目初始化，建立最小可打开网页、基础目录结构、开发日志和第一版设计说明，为后续实现最小可玩版本打底。

## 核心玩法概述

- 在 15 个纪元内维持文明存续。
- 调度“户”采集食物、燃料、材料。
- 通过道路扩张活动范围，建设聚落和仓库。
- 研究科技来提升生存能力或解锁新行动。
- 在灾难季中承受损失并尝试恢复。
- 文明灭亡后进入“文明遗产”选择，将部分成果传给下一世文明。
- 成功撑过第 15 纪后通关，并显示用了多少世、损失了多少户。

## 当前开发阶段

项目处于早期 Demo 初始化阶段。当前只包含静态页面、模块占位和文档骨架，尚未实现完整游戏循环。

## 如何本地运行

本项目暂不依赖构建工具或外部服务。直接用浏览器打开 `index.html` 即可查看当前页面。

后续如果加入本地开发服务器，会在此处补充运行命令。
